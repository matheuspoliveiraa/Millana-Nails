# Millana Nails Designer

Site institucional desenvolvido para a Millana Nails Designer, profissional especializada em design e embelezamento de unhas.

O projeto tem como objetivo apresentar a marca, divulgar os serviços oferecidos, exibir o portfólio de trabalhos e facilitar o contato e agendamento de clientes por meio do WhatsApp.

O site foi idealizado com uma identidade visual elegante e profissional, proporcionando uma experiência moderna, responsiva e acessível para todos os dispositivos.
